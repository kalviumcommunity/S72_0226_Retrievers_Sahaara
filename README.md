## 🚀 Getting Started

```bash
# Clone repository
git clone https://github.com/kalviumcommunity/S72_0226_Retrievers_Sahaara.git

# Navigate to app
cd sahara

# Install dependencies
flutter pub get

# Run app
flutter run -d chrome
```
